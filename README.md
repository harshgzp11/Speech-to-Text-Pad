# Speech to Text Pad

A simple web application that converts speech into text using the Web SpeechRecognition API.  
Users can start/stop voice recording, save their notes, delete individual notes, and clear all notes.  
All notes are stored in the browser using localStorage.

---

## Features

- Convert speech to text in real time  
- Start and stop listening with buttons  
- Save notes for later  
- Delete individual notes  
- Clear all saved notes  
- Notes remain saved even after refreshing the page (localStorage)  
- Simple and clean user interface

---

## Technologies Used

## How to Use

1. Open the application in the browser  
2. Click **Start Listening** to begin speech recognition  
3. Speak into your microphone  
4. Your speech will appear as text in the textarea  
5. Click **Save Note** to save the note below  
6. Each note can be deleted individually  
7. Click **Clear All Notes** to remove everything
